# Engine sounds

Original procedural engine audio created for this project by `tools/generate_engine_audio.py`.
No external samples or recordings are used. The generated WAV files may be used,
modified and redistributed with this project without additional attribution.

Six distinct styles: electric, racing two-stroke, heavy diesel, V-twin, muffled
touring and worn single-cylinder. Each has idle/load layers, a distinct turbo loop
and a release one-shot. Dusty adds uneven combustion, misfires and metallic rattling.
Runtime pitch follows speed and throttle; layer volume follows engine load.
