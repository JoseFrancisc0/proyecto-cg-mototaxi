# Grafitis con transparencia

Cuatro diseños manuales de Lucas Anton Gomez, [3DTexel](https://3dtexel.com/decals/), CC0. Se usan los mapas públicos de color y opacidad a 1K. Fuentes individuales en `catalog.json`. Se aplican como pintura en muros, con máscara de transparencia. No se contrataron generadores ni se utilizaron fotografías de calles como decal.
